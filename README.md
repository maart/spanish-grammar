# Испанский справочник

Автономный HTML-справочник по базовой грамматике испанского языка для русскоязычного пользователя. Проект задуман как быстрый офлайн-справочник, а не как тренажер упражнений: открыть файл, найти глагол, открыть справочник времен, проверить исключения или освежить правило.

## Что внутри

- **Глаголы**: поиск по инфинитиву, форме и русскому переводу без ограничения количества результатов, недавние глаголы, возврат к выдаче, карточка с основными временами (включая Presente de Subjuntivo и императив) и сгруппированным полным спряжением.
- **Справочник времен**: логические группы времен, быстрые переходы, образование, признаки времени и исключения по кнопке.
- **Наклонения**: indicativo, subjuntivo, imperativo и condicional с пояснениями, триггерами и примерами. Для imperativo есть отдельные подсказки по неправильным `tú`-формам и местоимениям.
- **Шпаргалки**: короткие таблицы по местоимениям, предлогам, условным предложениям, косвенной речи и похожим конструкциям; поиск по названию и тексту шпаргалок.
- **Учебник**: 60 интерактивных уроков по базовой грамматике с теорией на русском или испанском, автоматической проверкой и сохранением прогресса. Уроки охватывают существительные и артикли, прилагательные и сравнение, числительные, относительные и личные местоимения, ser, estar, tener, hay, настоящее время (модели спряжения и другие употребления), глаголы с me/te/se и gustar, estar + gerundio, pretérito indefinido и pretérito perfecto.
- **План обучения**: каркас маршрута по уровням A0–C2 с выбором текущего уровня; подробное наполнение — следующий этап.
- **Избранное**: список глаголов для повторения, настраиваемая проверка инфинитивов и спряжений, разбор и повтор ошибок.

## Особенности

- Один файл: `spanish-grammar.html`.
- Работает без сборки, сервера и зависимостей.
- Данные и прогресс учебника хранятся локально внутри HTML и `localStorage`.
- Кнопки «Сохранить прогресс» и «Загрузить прогресс» в футере переносят избранное, статистику, прогресс учебника и плана и настройки через JSON-файл — например, на другое устройство или после очистки браузера.
- Избранное, настройки проверки и тема сохраняются в `localStorage`. Пока тема не выбрана вручную, приложение следует системной светлой или тёмной теме.
- Испанский текст размечен `lang="es"` для экранных дикторов и переносов.
- На телефоне разделы переключаются нижней панелью: Глаголы, Времена, Курс, Избранное и меню «Ещё» (Шпаргалки, Наклонения, План).
- Подходит для пересылки как один файл.
- Ориентировано на испанский вариант языка, включая `vosotros`; орфография форм — по нормам RAE 2010 (например, односложные hui, huis, rio, guio пишутся без тильды).

## Как открыть

Самый простой вариант: открыть `spanish-grammar.html` напрямую в браузере. Можно дважды кликнуть по файлу в Finder или перетащить файл в окно браузера.

На macOS то же самое можно сделать из терминала:

```bash
open spanish-grammar.html
```

Дополнительный вариант: запустить локальный сервер.

```bash
python3 -m http.server 8001
```

После этого открыть:

```text
http://localhost:8001/spanish-grammar.html
```

## Текущий статус

MVP 1.19. Приложение уже можно использовать как автономный справочник и интерактивный учебник: первые 60 уроков охватывают существительные, артикли, прилагательные, сравнение, числительные, относительные и личные местоимения, а также ser, estar, tener, hay, настоящее время (модели спряжения и другие употребления), глаголы с me/te/se и gustar, estar + gerundio, pretérito indefinido и pretérito perfecto. Уроки 51–60 добавляют presente для планов, инструкций и просьб; периоды времени с desde, desde hace и hace… que; глаголы с me, te, se и их противопоставление; gustar и похожие глаголы; estar + gerundio и его сравнение с presente; pretérito indefinido правильных и неправильных глаголов; pretérito perfecto. Уроки 41–50 добавляют местоимения после предлогов; полные значения ser/estar и их контрасты; tener и конструкции количества hay; различение наличия и местоположения; полные окончания presente для трёх групп, глаголы с чередованием и неправильные формы. Каждый урок содержит расширенные двуязычные опорные блоки с формами, ограничениями, исключениями, примерами и моделями употребления; уроки 21–50 дополнительно содержат подробные модели преобразования и контрастов из исходной структуры. Оглавление организовано как аккордеон тем первого уровня с перечнем входящих уроков и общими действиями раскрытия/скрытия всех тем. Прогресс, ответы и ошибки сохраняются локально; незаполненные ответы не засчитываются как проверенные. Само приложение остается одним HTML-файлом, который можно открыть без установки. Скрипт `validate-conjugations.js` используется при разработке для автоматической проверки данных.
